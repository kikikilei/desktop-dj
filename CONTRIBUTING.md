# Contributing

Desktop DJ welcomes small, playful, noncommercial contributions.

By submitting a contribution, you confirm that you have the right to share it
and agree that first-party code and visual assets will be distributed under
the licenses described in `LICENSE.md`.

## Before opening a change

- Keep personal names, private handoff notes, account data, and listening
  history out of the repository.
- Do not commit `Build/`, `.build/`, generated archives, or local app bundles.
- Keep Preview-only controls behind a debug configuration instead of creating
  a second product fork.
- Preserve the third-party license and source notices for `nowplaying-cli`.
- Run `./build.sh`; a successful build verifies macOS 13 deployment metadata,
  Intel and Apple Silicon slices, the embedded bridge, and the packaged app.

For animation and skin contributions, follow `DESIGN-HANDOFF.md`.
